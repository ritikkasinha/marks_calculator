# Project Statement

## Project Title

Grade Calculator

## Problem Statement

Calculating percentage and grades manually can take time and may lead to calculation mistakes. Students often need to calculate their total marks, percentage, and grade based on the marks obtained in different subjects.

The **Grade Calculator** is a simple Python-based project developed to make this process easier and faster. The system takes marks entered by the user, calculates the total marks and percentage, and determines the appropriate grade using predefined conditions.

The project also provides an opportunity to understand and apply basic Python programming concepts such as user input, variables, arithmetic operations, conditional statements, functions, and basic error handling.

## Scope of the Project

The scope of the Grade Calculator is to provide a simple and easy-to-use system for calculating a student's percentage and grade.

The project includes:

* Taking marks as input from the user.
* Calculating total marks.
* Calculating the percentage.
* Determining the grade based on the percentage.
* Displaying the final result clearly.
* Validating basic user input.

The project is currently designed as a basic console-based Python application. In the future, it can be extended with features such as student records, multiple student management, data storage, and a graphical user interface.

## Target Users

The main target users of this project are:

* Students who want to calculate their percentage and grade quickly.
* Teachers who want a simple tool for checking basic results.
* Beginners learning Python programming and basic application development.

## High-Level Features

### 1. Input and Validation

The system accepts marks entered by the user and performs basic validation to ensure that the entered values are suitable for calculation.

### 2. Marks and Percentage Calculation

The system calculates the total marks obtained and uses the total to calculate the student's percentage.

### 3. Grade Evaluation

The calculated percentage is checked against predefined grade conditions, and the appropriate grade is displayed.

### 4. Result Display

The system displays the total marks, percentage, and final grade in a clear and understandable format.

## Project Objective

The main objective of this project is to develop a simple Python application that can calculate a student's percentage and grade accurately while demonstrating the practical use of fundamental Python programming concepts.

## Expected Outcome

The expected outcome of the project is a functional and easy-to-use Grade Calculator that reduces manual calculation work and provides the required result quickly and clearly.
