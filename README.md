# Grade Calculator

## Project Overview

Grade Calculator is a simple Python project that helps calculate a student's percentage and grade based on the marks they enter. The program takes the marks as input, calculates the percentage, and then uses simple if-else conditions to determine the appropriate grade.

I developed this project as a college project to practice the basics of Python programming, such as taking user input, using variables, performing calculations, and applying conditional statements. The main aim of the project is to make the process of calculating grades quick and easy.

## Features

* Takes marks as input from the user
* Calculates the student's percentage
* Determines the grade based on the percentage
* Displays the final result
* Simple and easy to use

## Technologies Used

## Requirements

* Python 3.x
* VS Code or any Python-supported code editor

## How to Install

1. Clone this repository:

```bash
git clone https://github.com/ritikkasinha/marks_calculator/edit/main/README.md
```

2. Open the project folder in VS Code.

3. Make sure Python is installed on your computer.

## How to Run

Run the Python file using the following command:

```bash
python main.py
```

Enter the required marks when the program asks for them. The program will calculate the percentage and display the corresponding grade.

## Testing

The project can be tested by entering different marks and checking whether the calculated percentage and grade are correct.

For example:

* Enter marks that result in a high percentage and check the corresponding grade.
* Enter marks from different grade ranges.
* Test the program with different valid inputs.
